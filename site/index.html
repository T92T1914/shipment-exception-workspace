Static project explainer

Change a shipment record without losing its history.

Shipment Exception Workspace is a small React, Python and PostgreSQL application for creating, finding, assigning and resolving synthetic exceptions. Its useful question is what happens when two edits compete or a committed response disappears.

This static page explains the project. The separate hosted synthetic demo lets visitors browse records and history as a read-only reviewer. Choose Enter synthetic demo; do not enter real shipment or personal data. The installable application and operator walkthrough remain available below.

One change. A durable history.

The server checks the current session, organization and operator role. A successful change updates the record, inserts its history event and saves its response receipt in one transaction. The expected version prevents an older edit from overwriting a newer one. A reviewer can inspect records but cannot make business changes.

A response can be lost after the change commits.

  1. Create a synthetic receiving-appointment exception at version 1.
  2. Assign Sam, reaching version 2. A competing edit that still expects version 1 is refused.
  3. Assign Casey with the current version. The server commits version 3, but the test deliberately interrupts its response.
  4. Explicitly retry the retained same intent with its original key and body. Current access still has to be valid. The saved response returns without another assignment event.
  5. Resolve the record, reaching version 4. Its four events remain visible after reload.

A receipt response is historical. A separate current-state refresh reads any later changes. Session or access recovery does not automatically POST a business change, and retiring an uncertain client request cannot undo a commit.

What the result establishes.

The project demonstrates organization-scoped access, operator/reviewer roles, version conflicts, atomic history and receipts, and explicit recovery through an installed synthetic consumer. Tests and captures have their own recorded source and environment identities.

It has no carrier integration, operational users or production qualification. The separate hosted reviewer passed bounded HTTPS, server-denial, desktop/narrow and instance-restart checks on October 27, 2026. Its history is provisioned synthetic fixture data.
